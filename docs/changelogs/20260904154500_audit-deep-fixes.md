# Audit deep fixes

## Participants

- Andrei Makarov

## Decisions

- Treat the audit high set as bugfixes of unintended writes, not a new user-facing contract. Skip RFC. Leave the gem version at 0.1.1 until release.
- Create the review row on the first span save. Show-page GET uses an in-memory preview.
- Browsing another content version is read-only. Create returns 422 with This version is read-only. when the displayed version is not the pin. Displayed version 0 is a real value.
- Stimulus JSON key stays annotation. Review PATCH uses review. Missing spans return Annotation not found. Cross-reviewer span mutations and show return Annotation access denied.
- Ship migrations as ActiveRecord 7.1. PostgreSQL uses jsonb, pgcrypto, and the GIN metadata index. SQLite uses json and string UUID columns.
- Dummy schema version stays 0 so engine timestamps still run. Host tables live in dummy schema.rb. Annotation tables come from engine migrations via EngineSchema.load!.
- Restrict the spans index to the current reviewer. Member actions still load another reviewer's span so authorization can return 403.

Later pass 20260904161200: cut 0.1.2. See usr/docs/changelogs/20260904161200_release-0-1-2.md.

## Effects

- Opening a subject show page no longer inserts or updates annotation_reviews.
- The first saved span creates the review and returns annotation_review_id so the panel can keep writing to that row.
- A save against a different content version is refused. The composer is hidden when the panel is read-only.
- Review form updates accept review_status and notes only. metadata_json cannot flip stale or follow-up flags from the request.
- JSONL export streams through an Enumerator. Copy text no longer includes a Reviewer ID line. Exporter preloads annotations and subject once per batch.
- Request specs cover span JSON create, update, destroy, copy_text, export_jsonl, cross-reviewer 403, GET without write, and browse without create. The install spec runs the shipped migration chain on a fresh SQLite file.
- README Ruby floor is 3.4. README states SQLite json and PostgreSQL jsonb. The test workflow runs on pull_request.
- Dummy ActiveAdmin CSS and JS placeholders exist so HTML index requests can render under Propshaft.
